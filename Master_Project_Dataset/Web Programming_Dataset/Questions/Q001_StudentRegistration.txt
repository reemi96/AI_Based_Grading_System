Question_ID: Q001

Title: Student Registration Form Validation

Problem Statement: 
Write a JavaScript program that validates student registration information.
The program should ask for:
- Student Name
- Student Age
- Student Email

Validation Rules:
1. Student name must not be empty.
2. Student age must be 18 or older.
3. Email must contain '@' and '.'.

If all validations pass, display: Registration Successful
Otherwise display the appropriate error message.

Requirements:
1. Read student name.
2. Read student age.
3. Read student email.
4. Validate name is not empty.
5. Validate age is at least 18.
6. Validate email format.
7. Display appropriate message.
