Question_ID: Q005

Title: Password Strength Checker

Problem Statement: 
Write a JavaScript program that checks the strength of a password.
The program should read a password from the user.

A password is considered strong if it satisfies all of the following conditions:
1. The password length is at least 8 characters.
2. The password contains at least one uppercase letter.
3. The password contains at least one lowercase letter.
4. The password contains at least one digit.
If all conditions are met, display:
Strong Password
Otherwise display:
Weak Password

Requirements:
1. Read password from the user.
2. Check password length.
3. Check for uppercase letter.
4. Check for lowercase letter.
5. Check for digit.
6. Display Strong Password if all conditions are satisfied.
7. Display Weak Password otherwise.
