Question_ID: Q003

Title: Word Frequency Counter

Problem Statement: 
Write a Python program that reads a sentence from the user and counts 
how many times each word appears.
The program should display each word followed by its frequency.

Requirements:
1. Read a sentence from the user.
2. Split the sentence into words.
3. Count the occurrences of each word.
4. Store frequencies in a dictionary.
5. Display each word with its frequency.
6. Preserve the order of first appearance.
