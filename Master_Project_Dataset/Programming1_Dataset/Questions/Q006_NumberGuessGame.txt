Question_ID: Q006

Title: Number Guess Game

Problem Statement: 
Write a C# program that implements a simple number guessing game.
The program should:
- Store a secret number with the value 25.
- Ask the user to guess the number.
- If the guess is smaller than the secret number, display:
   "Too Low"
- If the guess is greater than the secret number, display:
   "Too High"
- Continue asking the user until the correct number is guessed.
- When the correct number is guessed, display:
   "Correct!"

Requirements:
1. Store the secret number as 25.
2. Read guesses using Console.ReadLine().
3. Convert the input to an integer.
4. Use a while loop.
5. Compare the guess with the secret number.
6. Display the appropriate message.
7. Stop when the correct number is guessed.
