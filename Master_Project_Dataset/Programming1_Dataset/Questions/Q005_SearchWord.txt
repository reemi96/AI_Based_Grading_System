Question_ID: Q005

Title: Search Word in Array

Problem Statement: 
Write a C# program that stores 5 words in an array.
After storing the words, ask the user to enter a search word.
If the word exists in the array, display:
True
Otherwise display:
False

Requirements:
1. Read 5 words from the user.
2. Store the words in an array.
3. Read a search word.
4. Search the array for the word.
5. Display True if the word exists.
6. Display False if the word does not exist.
7. Stop searching once the word is found.
